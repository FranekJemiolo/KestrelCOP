The 4-Tier Zero-Cloud Architecture

      
Strict physical and logical separation guarantees survivability when wide-area connectivity is severed.


      

        

          
Tier 1: Operator Edge Node

          
Edge Compute & Sensor Bus

          
Runs on chest-mounted ruggedized Android or Raspberry Pi 5. Ingests NMEA GPS and BLE biometrics on an async loop while isolating YOLO ML inference in a dedicated process.

          
    
            
  • Python 3.12+

  • Pydantic v2

Tier 2: Tactical Transport

          
Mesh Radio Pub/Sub

          
Emulates volatile MANET networks over local Mosquitto MQTT. Incorporates bounded collections.deque buffers to discard stale coordinates during prolonged RF blackouts.

          
    
            
  • Eclipse Mosquitto
    • 
            
  • aiomqtt
    • 
            
  • QoS 0 / QoS 1
    • 
            
  • Ring Buffering

Tier 3: Command Collector

          
Immutable Event Backbone

          
Runs on local k3s edge servers in the Tactical Operations Center. Commits all Cursor-on-Target events into an append-only Kafka log for real-time analytics and PostGIS indexing.

          
    
            
  • k3s
    • 
            
  • Strimzi Kafka
    • 
            
  • PostgreSQL 16

  • PostGIS 3.4

Operational Validation Matrix

      
Definitive acceptance criteria mapping engineering milestones directly to battlefield readiness.


      

        

          
            

              Milestone
              Component

              M1
              Schemas & Event Bus
              Data Integrity: Reject corrupted sensor inputs without crashing the node.
              Inject malformed JSON/NMEA at 1,000 pkts/s; system must drop bad records and maintain event loop.
            

            

              M2
              Asynchronous GPS & BLE
              Continuous Awareness: Automatic hardware reconnection resilience.
              Unplug USB GPS and turn off BLE strap for 5 mins; stream must auto-recover in < 3s upon reconnection.
            

            

              M3
              Isolated ML Pipeline
              Zero Latency Starvation: Heavy vision processing cannot throttle vital metrics.
              Run YOLO at 100% CPU utilization; biometric alerts must post to bus with zero queue starvation (<15ms).
            

            

              M4
              Mesh Transport Link
              DIL Network Resilience: Stale-data expiration upon reconnection.
              Sever MQTT link for 10 mins; on reconnect, only freshest coordinates and alerts are published; stale tracks drop.
            

            

              M5
              Edge Observability
              Field Deployability: Zero-touch single-command deployment.
              Cold boot container stack on Raspberry Pi 5 with Wi-Fi disabled; achieve operational state in < 15s.
